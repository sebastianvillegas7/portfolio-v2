# Portfolio V2

Portfolio profesional de Sebastián Villegas.

Nueva versión desarrollada desde cero con una arquitectura moderna basada en Next.js. El portfolio anterior en Angular se conserva únicamente como referencia para recuperar contenido y assets cuando sea necesario.

## Stack

- Next.js 16
- React 19
- TypeScript
- Tailwind CSS 4
- Motion
- OGL / WebGL
- shadcn/ui
- Animata
- Recursos visuales externos adaptados al proyecto
